# gym-progress-analysis-3mo
3-month personal gym training log analyzed in Excel strength progress &amp; volume trends by muscle group.

Tracking my personal gym training (sets, reps, weight, RPE) over 3 months 
to analyze strength progress and training volume by muscle group.

## Status
Currently in data collection phase (started Sept 28, 2026). 
Full analysis with pivot tables and charts coming at completion (~Week 12).

## Tools
Excel/Google Sheets (SQL and Python analysis planned as a follow-up)

## Data columns
Date | Exercise | Muscle Group | Set # | Reps | Weight (kg) | RPE (1-10)
